# PDF Modder 3.0.13

## Selección predeterminada por línea

Al entrar en **EDITAR**, el selector **Seleccionar** comienza en **Línea**.
El lienzo utiliza ese mismo alcance desde el inicio. Se puede cambiar
manualmente a Palabra, Carácter, Párrafo u otro alcance disponible.

Incluye la corrección de 3.0.12 que recupera el panel derecho después de
contraer o desplegar el panel izquierdo en Lectura.

Entrega Windows x64 con instalador, versión portable y código fuente. El canal
**Buscar actualizaciones** utiliza el instalador y su manifiesto de integridad
publicados en GitHub Releases.
