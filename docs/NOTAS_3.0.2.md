# PDF Modder 3.0.2

Corrige tres incidencias de edición y conserva las funciones de la versión 3.0.0:

- Permite editar texto en tablas y elementos etiquetados con atributos de
  disposición compatibles. Conserva sus cuadros de disposición cuando el texto
  permanece dentro y actualiza cuadros exclusivamente textuales verificables.
  Las clases compartidas y los demás elementos conservan sus propiedades.
- Quitar etiquetas conserva la versión de PDF, los metadatos estándar y propios,
  XMP y los destinos de los marcadores. Mantiene la comprobación del texto y la
  apariencia antes de aplicar la operación al historial.
- Aceptar reutiliza el PDF ya validado para la vista previa cuando coincide
  exactamente el borrador y la revisión del documento. Cualquier cambio de texto,
  formato o área exige una validación nueva. Los PDF etiquetados comparten el
  análisis de operadores entre las comprobaciones de estructura y bloques de
  texto, conservando la revisión de Forms y relaciones accesibles.

Instalador Windows x64 y alternativa portable. **Buscar actualizaciones** recibe
esta versión mediante el manifiesto público con comprobación de tamaño y SHA-256.
